# Demo notes — Aether landing page

1. Start the server and open <http://localhost:8000>. The sticky header shows the Aether mark, four links and the "Start free" button.
2. Scroll down a little. The header stays pinned to the top with a translucent background while the hero scrolls underneath it.
3. Hover the nav links: a thin orange underline grows from the left. Hover the buttons and cards to see the small lifts.
4. Click "Features". The page jumps to the six feature cards. Each card has a hand-drawn line icon.
5. Click "How it works". The dark section lists the three steps as 01, 02 and 03.
6. Click "Demo". This section is labelled as placeholder content — the testimonials are sample copy, not real reviews.
7. Click "Pricing". Three plans are shown; the middle plan is highlighted as "Most popular". The buttons are anchors back to the top of this demo.
8. Scroll to the footer. `hello@aether.works` opens a mail client, and the X, GitHub and LinkedIn icons are labelled placeholder links.
9. Resize the browser to 768px and then 360px wide. The nav wraps onto two rows, cards stack, and no text is cut off.
10. Disable JavaScript in the browser's DevTools and reload. Nothing changes — the page never loads a script.

There is no sign-up flow behind the buttons. This is a static landing page, so all CTAs either jump to a section or open an email.
